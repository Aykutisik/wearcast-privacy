Datos que Recopilamos

Wearcast procesa las fotos que seleccionas para la función de prueba virtual. Estas fotos solo se envían a Replicate (replicate.com) para el procesamiento de IA y no se almacenan en tu dispositivo. Cuando compras créditos, se comparte un registro de compra anónimo con RevenueCat para estadísticas de ventas (ver Servicios de Terceros). No recopilamos tu nombre, correo electrónico, contactos ni ubicación.

Cómo se Usan tus Fotos

Las fotos de ropa y persona seleccionadas se envían a los servidores de Replicate para que el modelo de IA pueda vestirte virtualmente. La imagen se elimina de Replicate tras el procesamiento. Tus fotos no se comparten con terceros ni se usan para publicidad.

Datos Faciales

Wearcast no realiza reconocimiento facial ni recopila identificadores biométricos o plantillas faciales. Las fotos que seleccionas pueden contener un rostro; la app las procesa únicamente como imágenes normales para generar la prueba virtual que solicitas. Los datos faciales de tus fotos: (1) se usan únicamente para generar esa única imagen de prueba virtual; (2) se transmiten de forma segura solo a nuestro proveedor de procesamiento de IA, Replicate (replicate.com), para esa generación única; (3) nunca son almacenados por Wearcast — ni la app ni nuestro servidor proxy guardan copia alguna; Replicate procesa las imágenes de forma transitoria y las elimina conforme a su política de privacidad, y los archivos generados expiran automáticamente en aproximadamente una hora; (4) nunca se usan para identificación, seguimiento, publicidad, análisis o entrenamiento de modelos de IA, y nunca se comparten con ninguna otra parte.

Servicios de Terceros

Replicate (replicate.com) procesa tus fotos para generar la imagen de prueba usando el modelo de imagen Nano Banana de Google. Consulta replicate.com/privacy.

RevenueCat (revenuecat.com) recibe un registro de cada compra dentro de la app — producto, precio, moneda, fecha y un identificador aleatorio de la app generado en tu dispositivo — para que podamos ver estadísticas de ventas. No recibe tu nombre, correo electrónico ni fotos, y los datos no se usan para publicidad ni seguimiento. Consulta revenuecat.com/privacy.

Apple App Attest: para proteger nuestro servicio contra abusos, la app usa App Attest de Apple para demostrar que las solicitudes provienen de una copia auténtica de Wearcast en un dispositivo real. Usa una clave criptográfica creada en tu dispositivo y no contiene datos personales.

Sistema de Créditos

Los créditos que compras se almacenan localmente en tu dispositivo. Los pagos se procesan a través de Apple App Store y están sujetos a la política de privacidad de Apple. Un registro de la compra se comparte con RevenueCat como se describe arriba.

Privacidad de Menores

Esta app no está dirigida a usuarios menores de 13 años y no recopila datos de este grupo de edad a sabiendas.
