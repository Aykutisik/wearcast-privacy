Datos que Recopilamos

Wearcast procesa las fotos que seleccionas para la función de prueba virtual. Estas fotos solo se envían a Replicate (replicate.com) para el procesamiento de IA y no se almacenan en tu dispositivo.

Cómo se Usan tus Fotos

Las fotos de ropa y persona seleccionadas se envían a los servidores de Replicate para que el modelo de IA pueda vestirte virtualmente. La imagen se elimina de Replicate tras el procesamiento. Tus fotos no se comparten con terceros ni se usan para publicidad.

Servicios de Terceros

La app usa la API de Replicate para el procesamiento de imágenes con IA. Puedes leer la política de privacidad de Replicate en replicate.com/privacy.

Sistema de Créditos

Los créditos que compras se almacenan localmente en tu dispositivo. Los pagos se procesan a través de Apple App Store y están sujetos a la política de privacidad de Apple.

Privacidad de Menores

Esta app no está dirigida a usuarios menores de 13 años y no recopila datos de este grupo de edad a sabiendas.
